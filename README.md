# 📚 Exercícios de POO

Repositório dedicado à prática de **Programação Orientada a Objetos (POO)**, com exercícios e pequenos sistemas desenvolvidos em diferentes linguagens: **Java**, **C#** e **Python**.

> Este é um repositório de **estudos**. O objetivo é fixar conceitos de POO comparando como cada linguagem os implementa — o código está em evolução constante conforme avanço no aprendizado.

---

## 🎯 Objetivo

Praticar e consolidar os pilares da Programação Orientada a Objetos:

- **Herança**
- **Polimorfismo**
- **Encapsulamento**
- **Abstração**
- **Interfaces**

Ao replicar exercícios semelhantes em linguagens diferentes, a ideia é entender melhor as particularidades de sintaxe e as diferenças de abordagem de cada uma para os mesmos conceitos de POO.

---

## ▶️ Como executar

Cada subpasta de exercício pode ter instruções próprias de execução, mas de modo geral:

**Java**
```bash
javac NomeDoArquivo.java
java NomeDoArquivo
```

**C#**
```bash
dotnet run
```

**Python**
```bash
python nome_do_arquivo.py
```
